live-pipeline · a mini TRADE360

One match feed in, live 1X2 prices out.

A real-time sports data pipeline in the style of LSports' TRADE360. A producer replays World Cup matches as RabbitMQ-style messages. A consumer rebuilds match state from those messages and prices the 1X2 market live, minute by minute, with an xG-driven model calibrated on 82,000 shots across four seasons of the EPL and La Liga plus three World Cups.

Python, stdlib-only core, runnable locally — source on GitHub.

01 · architecture

How the messages flow

Everything is a JSON envelope on a topic exchange. The producer publishes the match feed, the consumer prices it and publishes markets back. If a consumer joins late, it notices the gap in message sequence numbers and asks the producer for a snapshot — then carries on as if it had been there all along.

03 · the model

One formula, repriced every minute

The consumer keeps a running estimate of how many goals each team is still likely to score, then turns that into 1X2 probabilities with a Poisson grid.

lam_rem(t) = ((90 − t) / 90) · [ (1 − w) · λ_prematch  +  w · 90 · pace ]
  • λ_prematch is what we expected before kick-off, from each team's fitted attack and defence rates — calibrated per competition on 3,272 matches (EPL + La Liga 2022–26 plus World Cups 2018/22/26), recency-weighted so current form dominates.
  • pace is what's actually happening: the team's xG over the last 15 minutes, per minute. A team peppering the goal gets its remaining-goals estimate pulled up; a parked bus pulls it down.
  • w = 0.35 blends the two. The (90 − t)/90 factor just scales it to the minutes left.
  • With a remaining-goals rate for each side, a small Poisson grid sums P(win), P(draw), P(lose) over every remaining scoreline, on top of the current score.
  • Home advantage is a fitted ×1.13 boost to the home side's rate, learned from league matches. World Cup venues are neutral, so the replays on this page don't use it.
  • 90-minute market convention: stoppage time counts — every league match and World Cup group game folds 90+' events into minute 90 — but extra time never does. A knockout tie that's level at 90' settles as X, whatever happens after.

Rates are recency-weighted (0.8 per season) with empirical-Bayes shrinkage, so league teams with 152 matches are far better estimated than World Cup sides seen a handful of times.

Lower is better. Honest holdout: trained on 2022–25 plus World Cups 2018/22, tested blind on 2025–26 and World Cup 2026 — 864 matches. Both variants clearly beat always quoting the base rates, and the honest caveat: at this scale the no-momentum w = 0 variant edges out the momentum blend at most checkpoints — 15-minute xG is noisy. The live demo keeps w = 0.35 so momentum stays visible; the chart reports both so the number isn't oversold.

05 · run it yourself

Same pipeline, in your terminal

Stdlib only — no installs needed for the in-memory broker. The tests cover the model, the message contracts and the snapshot recovery path.

git clone https://github.com/RShiri/RShiri.github.io && cd RShiri.github.io
python3 live-pipeline/run_demo.py --list
python3 live-pipeline/run_demo.py --match 2026_06_17_Argentina_vs_Algeria --speed 600
python3 live-pipeline/run_demo.py --match 2026_07_04_1J_vs_2H --speed 600 --late-join 60   # snapshot recovery
python3 -m pytest live-pipeline/tests -q

Want the real broker? docker run -p 5672:5672 rabbitmq:3, pip install pika, then add --broker rabbit to any run — same messages, now over an actual RabbitMQ topic exchange.
