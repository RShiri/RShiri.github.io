RabbitMQ

You already built LSports' delivery pattern in live-pipeline. This page turns what you coded into crisp interview answers.

Why LSports cares RabbitMQ is how TRADE360 reaches customers: sportsbooks consume fixture, livescore and market messages from queues bound to their feed. It's named explicitly in LSports job requirements ("real-time messaging systems such as RabbitMQ and Kafka").

The mental model

RabbitMQ is a post office between services. Producers never talk to consumers directly:

  • Producer publishes a message to an exchange with a routing key (an address, like feed.fixture_101).
  • The exchange routes copies into every queue whose binding matches the key.
  • Consumers read from queues and acknowledge (ack) each message once processed.

Exchange types: direct (exact key match), fanout (everyone gets everything), topic (pattern match on dot-separated keys — this is yours), headers (rare).

Topic routing patterns

Reliability: the questions they will actually ask

Consumer crashes mid-message?

If the consumer dies before acking, the broker requeues the unacked message and redelivers it to another consumer. That's why processing must be idempotent — the same message may arrive twice. (Auto-ack mode trades this safety for speed: crash = message lost.)

Broker restarts?

Three switches must all be on to survive a restart: durable exchange, durable queue, and persistent messages (delivery mode 2). Any one missing → data gone.

Consumer slower than producer?

The queue grows — RabbitMQ buffers, which absorbs spikes but not a permanent imbalance. Tools: prefetch (basic_qos(prefetch_count=N)) caps unacked messages per consumer so one slow consumer doesn't hoard; add consumers on the same queue for work-sharing; set queue length limits / TTLs so the broker doesn't eat all memory.

One queue, many consumers vs many queues?

Two consumers on the same queue split the messages (load balancing). Two queues bound with the same pattern each get a full copy (fan-out, one per subscriber) — that's how many sportsbooks each get the whole feed.
